# 🚐 سامانه مدیریت زحل

سامانه‌ی مدیریت جامع سفرهای سازمانی با قابلیت مدیریت رانندگان، برنامه‌های سفر، سوخت، پروانه‌ها و تنظیمات — با رابط کاربری مدرن، واکنش‌گرا و راست‌به‌چپ.

**لینک دمو:** 
---

## ✨ امکانات

### 📊 داشبورد
- نمایش آمار لحظه‌ای (کل رانندگان، برنامه‌ها، برنامه‌های فعال)
- دسترسی سریع به بخش‌های اصلی
- جدول آخرین برنامه‌ها و سوخت‌ها

### 👤 مدیریت رانندگان
- افزودن، ویرایش و حذف راننده
- جستجو بر اساس نام، کد ملی یا شماره موبایل
- نمایش کد یکتای راننده (D-XXXXX)

### 🗺️ مدیریت برنامه‌ها
- ایجاد برنامه سفر با مشخصات مبدا، مقصد، نوع بار و وضعیت
- فیلتر بر اساس وضعیت (در انتظار / در حال انجام / تحویل شده)
- تغییر وضعیت برنامه با یک کلیک

### ⛽ مدیریت سوخت
- ثبت سوخت با شماره پلاک و کارت
- بررسی وضعیت سوخت خودروها
- هشدار برای خودروهای بدون سوخت

### 📋 مدیریت پروانه‌ها
- ثبت پروانه با نوع، تاریخ انقضا و وضعیت
- هشدار خودکار برای پروانه‌های منقضی‌شده
- جستجو و فیلتر پروانه‌ها

### ⚙️ تنظیمات
- حالت تاریک / روشن
- فعال‌سازی/غیرفعال‌سازی اعلان‌ها
- تنظیمات سیستم (نام، نسخه، پشتیبان‌گیری)
- منطقه خطر: پاک‌سازی کامل داده‌ها

---

## 🛠️ تکنولوژی‌ها

| تکنولوژی | کاربرد |
|-----------|--------|
| HTML5 | ساختار صفحه |
| CSS3 (Grid + Flexbox) | چیدمان و استایل |
| Vanilla JavaScript | منطق برنامه و تعامل |
| localStorage | ذخیره‌سازی داده‌ها |
| Persian Date | مدیریت تاریخ  |
